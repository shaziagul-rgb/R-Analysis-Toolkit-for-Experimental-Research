# Provenance

## Archived figures (`gallery/`)

The images in `gallery/` were generated during PhD research. The original R
scripts and the participant-level data files used to make them are no longer
available. The figures are kept as an archival record only.

## Code in this repository

The code in `R/` is a new, general-purpose tool for group comparison and
plotting. It is **not** the original analysis code and it was **not** used to
produce the archived figures. Earlier versions of this repository contained
scripts that were reconstructed to resemble the archived plots; those have been
removed so the repository does not imply that the original analysis can be
reproduced.
