# Data availability

The original participant-level CSV/TXT files referenced by the PhD scripts
are currently unavailable.

The scripts therefore use repository-relative paths and document the
expected input filenames, but they cannot reproduce the original analyses
until the raw data are recovered.

Archived figures generated during the PhD are preserved under:

`figures/original/`

Do not create or upload synthetic participant-level data and present it as
the original research data. If the source data are recovered later, place
authorised/anonymised copies under `data/raw/` and rerun the analysis.
